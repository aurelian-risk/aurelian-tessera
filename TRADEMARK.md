# The Aurelian name and mark

The Mozilla Public License covers the code in this repository. It does not cover the name,
the wordmark or the logo - no software licence does. This page says what is fine without
asking.

## Fine, no permission needed

- Saying your work is **based on**, **derived from**, **built with** or **compatible with**
  Aurelian Tessera++.
- Naming Aurelian Tessera++ in documentation, articles, talks, comparisons and reviews,
  favourable or not.
- Keeping the name and the mark in an unmodified build you pass on. That is the point of
  them.
- Linking to this repository and to aurelian-risk.com.

## Please ask first

- Calling your own product, fork, service or company **Aurelian** or **Tessera++**, or a
  name close enough to be mistaken for either.
- Using the mark as the icon or logo of something that is not this project.
- Anything that reads as if this project produced, endorsed or supports your work.

## Modified builds

A fork is welcome - that is what the licence is for. What a fork should not do is present
itself as this project. Rename it, and say what it is derived from. Concretely: change the
product name in `src/profile/*/product.ts`, and keep the source reference in the built file
pointing at wherever your source actually is.

## The BSI's designations

"IT-Grundschutz", "Grundschutz++" and "BSI" are the Federal Office for Information
Security's own designations. This project uses them **descriptively**, to say which method
the software implements, and claims no right in them.

**This project is not affiliated with, endorsed by or certified by the BSI.** Whether a
security concept produced with it satisfies a certification scheme is decided by the
certification body, not by this tool. A fork that keeps the method should keep that
statement with it.

The ruleset the build carries is the BSI's, under CC BY-SA 4.0, with the attribution and
the record of changes in [`NOTICE.md`](NOTICE.md). Passing on an adapted ruleset carries
the share-alike obligation with it; the name policy above is separate from that and does
not relax it.
